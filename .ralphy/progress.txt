## 2026-02-04: Task 3 (complete) - Consolidate env parsing helpers

### What was done:
- Created `internal/envutil/envutil.go` package with:
  - `GetString(key, defaultVal string) string` - replaces `getEnvOrDefault`
  - `GetBool(key string, defaultVal bool) bool` - replaces `getEnvBoolOrDefault`
  - `GetInt(key string, defaultVal int) int` - replaces `getEnvIntOrDefault`

  - 10 test cases for `GetDuration()` (seconds, ms, minutes, hours, combined, fractional, invalid)

- Updated callers to use new envutil package:

  - `cmd/daemon/config.go`: Removed local `getEnvOrDefault`, `getEnvIntOrDefault`, `getEnvBoolOrDefault`, now uses envutil
  - `internal/notify/config.go`: Removed local `getEnvOrDefault`, `getEnvBoolOrDefault`, now uses envutil
