El **GEX Faker** reproduce datos históricos de opciones/GEX de GexBot sobre REST y
WebSocket — un sustituto (mock) de su superficie de datos principal, con una UI web
(Studio) y una CLI para agentes (`gexfakercli`). ¿Recién llegas? Empieza por el
[inicio rápido](quick-start/). ¿Construyes un agente? Apúntalo a
[`llms.txt`](../llms.txt) o a `knowledge/index.md`.
