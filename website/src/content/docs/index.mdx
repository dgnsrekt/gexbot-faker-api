The **GEX Faker** replays historical GexBot options/GEX market data over REST and
WebSocket — a drop-in mock for its primary data surface, with a web UI (Studio)
and an agent CLI (`gexfakercli`). New here? Start with the
[quick start](quick-start/). Building an agent? Point it at
[`llms.txt`](llms.txt) or `knowledge/index.md`.
